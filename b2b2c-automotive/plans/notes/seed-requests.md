# Seed requests

The seed package (`seed/`, `plans/SEED-PLAN.md` v2) is the source of truth for data contracts. A workstream that needs data the seed lacks does **not** edit the seed: it appends a row here and a `## Seed requests` section in its own workstream file. The seed owner (workstreams D, E, F) decides. Rows are appended; a decided row gets a status in the last column.
