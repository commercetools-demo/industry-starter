# Decisions

Source of truth for choices already made. If a task conflicts with a decision, keep the decision and write a question (JUNIOR-GUIDE section 8). Owner decisions are marked **(owner)**; verified platform facts **(verified)** with the date and how. `design.md` = `openspec/changes/b2b2c-automotive-design/design.md`.

| ID | Decision | Why / evidence |
| --- | --- | --- |
| D-001 | Two sites, two apps: the reseller **storefront** (`storefront/`, Next.js 16, multi-tenant by URL path `/[locale]/[store]`) and the **Malva Partner Portal** (`portal/`, Next.js 16; Supplier side = Malva, Seller side = the reseller). Seed package `seed/`. Brand names in the brief ("Supplier", "Seller") map onto the portal's two audiences. **(owner)** | design.md section 1; owner notes 2026-10-12 |
| D-002 | A **separate** commercetools project, key `spec-test-b2b2c-automotive`, reached through the MCP server `b2b2c-automotive` (read, create and update only; **no delete tool**), so create, delete and bulk update happen through seed scripts. No other commercetools project is ever touched. **(owner)** | owner notes; MCP read OK 2026-10-12 |
| D-003 | Specs are **flat OpenSpec capabilities** in `openspec/specs/` (`consumer-storefront/{bootstrap-and-structure,theming-design,design-*}`, `seller-portal/{bootstrap-and-structure,design-*}`) so the CLI sees them; the other directories there are generated templates and are not edited or implemented | design.md section 4.1 |
| D-004 | **Contentools** is the lightweight CMS for reseller-facing theme and pages. Everything is stored as commercetools custom objects keyed by the business unit / store key (theme: container `configuration`, key `{businessUnitKey}-theme`). Contentools hosts theme and pages. **(owner)** | design.md section 2 |
| D-005 | The portal **embeds Contentools' own components** (`ThemeManager`, `PageManager`, `ContentManager`); it builds no theme or page editor. The storefront renders Puck documents with `PuckRenderer`/`PuckDataRenderer` and reads the theme with `buildCssVars`; header, footer and commerce pages are application components reading the same theme through a token adapter | design.md section 2 |
| D-006 | The storefront reads **only the theme** from Contentools configuration (not `header`, `footer`, `facet`, `site-metadata`, `category-listing`, `translations`). Store name, logo and favicon are store settings. Theme history is Contentools' job; there is no contrast checking | design.md sections 2 and 9 |
| D-007 | **Tenancy:** the reseller is a commercetools **store**; the store key from the URL path is the Contentools namespace for theme, pages and content, and all branches share it. Contentools falls back to a `default` namespace only, which holds the Malva automotive theme. **No tenant or domain registry** in the apps; stores and domains are set up by hand in the Merchant Center and at hosting | design.md section 2 and question H (resolved) |
| D-008 | **Credentials:** the Contentools JWT is global to the project, written to a custom object (`contentools-configuration` / `contentools-jwt-token`) by the Merchant Center app, resolved and refreshed on the server. The browser calls Contentools only through a same-origin `/api/contentools` proxy that injects `x-project-key`; the portal proxy also rewrites the store key and keeps the JWT server-side. Reads need the project key, writes need a JWT and project validation | design.md section 2 (hardening beyond the skill: see Q-008) |
| D-009 | **Margin, not commission.** Resellers set their own retail prices and keep the margin. The prototype's Earnings page is dropped; Brand partnership remains as the guardrails page **(owner)** | design.md 4.3; owner notes |
| D-010 | **No fitting (installation) service** in this project; removed from all specs **(owner)** | design.md 4.4, decision 2026-10-12 |
| D-011 | **Fit-only by default** once a vehicle is selected (the prototype shows non-fitting parts with the filter off). Fitment is locked master data that resellers cannot edit | design.md 4.5, 3 |
| D-012 | The **store picker lists the reseller's branches**, not other resellers | design.md 4.6 |
| D-013 | **Currency, tax label, shipping threshold and country come from store configuration.** The prototype hard-codes CAD, HST 13% and "$99"; the portal uses EUR, 19% VAT, DACH | design.md 4.7 |
| D-014 | The **portal is not reseller-themed**; it keeps the admin kit (`tokens.admin.css`, Inter, near-black action, light/dark). The storefront uses the automotive kit (`tokens.automotive.css`, Poppins/Archivo/Public Sans, Garage Maroon) | design.md 4.8 |
| D-015 | **Design tokens only** in components; the prototype's raw hex values must not be copied | design.md 4.9 |

| D-018 | SDK majors stay on `@commercetools/platform-sdk` ^8 and `@commercetools/ts-client` ^4 (skill pins) although npm latest is 9.7.0 and 5.1.1; upgrade is a later follow-up | design.md question J (default; Q-009) |
