## 2. Goal and scope

**Goal.** A shopper opens the assistant from the header, describes a need ("something strong for an espresso machine", "a gift under 40 dollars", "where is my last order"), sees product cards, compares, builds a small cart with the assistant, and presses "Continue in my bag" to land in the normal bag and hosted Checkout.

**In scope** (owner, D-050): catalogue search and detail; assistant cart read, add, change quantity, remove; retrieval of an existing order of the signed-in shopper; the six cards; en-US and en-CA; both brands; US and Canada markets.

**Out of scope**: placing an order, address, shipping method, payment, discount codes (**the assistant never orders for the shopper**); policies/terms, fulfilment options, disclosures, web search, memory; changing or returning an order; brand scoping of results (Q-T-3); any commercetools API call other than the Shopper MCP tools (two owner-approved exceptions only: adopt-cart, Q-T-1, and the order ownership read, Q-T-2); the in-store companion; deploying.

## 3. Rules that are specific to this workstream (read twice)

1. **Upstream is the spec.** Clone `https://github.com/anthropics/commerce-agents` into a **new empty directory outside this repository** (for example `~/tmp/commerce-agents`) and keep it open. Cite the upstream path you port from in each file header. Never paste upstream code you have not read.
2. **Copy verbatim, do not paraphrase**: the system prompt, every tool description, gate and executor message strings, the four `SKILL.md` bodies, key order of every serialized payload. Rewording changes model behaviour and breaks the byte pin.
3. **The model never authors a displayed fact.** If you are about to add a `price`, `title`, `image` or `status` field to a presentation tool schema, stop: that is the contract breaking.
4. **No commercetools import under `lib/agent/**`** (lint). The only data source is the Shopper MCP. Anything the MCP cannot give is **absent**, never zero, never guessed.
5. **Prompt bytes are frozen.** Nothing from an environment variable or a request may render into the tool list or static system block. Only non-prompt caps are overridable.
6. **Money**: MCP amounts are integer minor units; the agent domain is a float in major units. Convert in exactly two modules (T-14 inbound, T-30 outbound). Never divide by 100; never copy upstream `formatMoney`.
7. **Never log or return a token, the MCP URL, a session id, a cart id or message text** (cart ids are credentials: the MCP documents no ownership check).
8. **Every secret** (`ANTHROPIC_API_KEY`, `SHOPPER_MCP_TOKEN_*`) is server only, never `NEXT_PUBLIC_`, never in a fixture, test, evidence file or chat. `scripts/shopper-mcp-probe.mjs` redacts before saving.
9. Test data is synthetic. Fixtures recorded from the live MCP are trimmed to the fields the mapper reads and carry no customer data (orders are replaced by hand-written synthetic ones).
10. When something is unclear, write a row in `plans/notes/questions-T.md`, keep the default, carry on.
