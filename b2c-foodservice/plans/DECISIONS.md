| D-041 | **In-store companion (workstream R).** The same codebase has a second experience, switched by the server variable `APP_MODE=instore` (default: the website). It refines D-001: the shop is still online-only (no point-of-sale, no store stock view); the companion is a phone shopping aid. `NEXT_PUBLIC_APP_MODE` is not created (no client code needs the mode). | Owner 2026-10-23 |
| D-042 | **Every cart made in in-store mode carries `custom.fields.orderType = 'in-store-purchase'`** on the custom type `instore-order-type` (an Enum field `orderType` with `in-store-purchase` and `online`, resource types `cart` and `order`). It is set at creation and by `setCustomType` or `setCustomField` on a cart that exists without it (rebuilt carts, checkout clones and reorders included). The hosted Checkout places the order, so a post-order hook sets the field on an order that lacks it (whether the platform copies `Cart.custom` to the order is not stated in the documentation read; live check M-R-03). The owner wrote "custom-object": it is read as the cart's custom type fields (Q-R-1). | Owner 2026-10-23, Q-R-1 |
