## Design
Tokens come **unchanged** from `design/malva/source/colors_and_type.css` (Store Launchpad). Foundations: `design/malva/DESIGN.md`.
- `app/globals.css`: `@import 'tailwindcss';` then a `:root { … }` block copied from the source (colours, type scale, spacing, radii, shadows, motion, focus ring, layout) and an `@theme { … }` block mapping the same names to Tailwind v4 theme variables (`--color-navy-900: var(--sl-navy-900)`, `--font-sans`, `--font-display`, `--radius-card: 8px`, spacing multiples of 4).
- Utility components in `@layer components`: `.btn`, `.btn-outline`, `.btn-white`, `.btn-outline-white`, `.btn-sm` (sharp, 48 px / 40 px), `.card`, `.tag`, `.input`, `.opt` (option card), `.stat`, `.cert`, `.quote`, `.phead`, `.cta`. Class bodies are the prototype's CSS translated 1:1.
- Fonts: self-hosted Inter 18pt (400, 500, 600, 700) and Inter Display 28pt (600, 700) via `next/font/local` with `display: 'swap'`; the TTFs are **not** in the repo yet: fetch them from the Claude Design project `d31829dd-8009-4a41-bf37-9fd3d8c6cec4` (`fonts/`) or from the official Inter release into `site/app/fonts/` (SIL OFL; keep the licence file). No request to Google Fonts.
- Design lint (`scripts/check-tokens.mjs`): fails on a raw hex colour or on a font-family outside Inter / Inter Display / the mono stack in `app/**/*.{css,tsx}` and `components/**`, except inside `globals.css` `:root`. Parity check: every `--sl-*` token in the source file exists in `globals.css` with the same value.
