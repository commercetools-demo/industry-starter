## Design
- `app/sitemap.ts` listing home, both listings, the 12 service pages, About, Request a quote, Privacy (absolute URLs from `NEXT_PUBLIC_SITE_URL`-style **non-secret** variable `SITE_URL`); portal and API excluded. `app/robots.ts` allows public paths, disallows `/*/account`, `/api`.
- Every public page: unique `<title>` (≤ 60 chars) and description (≤ 160), canonical, `hreflang` for `en-US` and `de-DE` (+ `x-default` = en-US), Open Graph and Twitter tags, one `h1`, descriptive link text; `lang` attribute.
- Structured data: `Organization` (name, logo, phone, contact point), `Service` on detail pages (L), `BreadcrumbList` on listings and details; no fake ratings.
- Portal pages: `noindex`.
- A test crawls the built route list and asserts uniqueness of titles/descriptions, canonical correctness, presence of OG image, and that no `sample: true` content is used in structured data.
- Absolute canonical/hreflang values must not depend on the request host in a way that breaks previews (use `SITE_URL`, fall back to the deploy URL).
