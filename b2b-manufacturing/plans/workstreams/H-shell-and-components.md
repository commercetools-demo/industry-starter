## Design
Layout and copy from `design/malva/DESIGN.md` § Page chrome and the prototype.
- **Top bar** (black, 40 px): left "24/7 emergency line: **0800 555 0142**" as `tel:` link; right "Client portal" (a `button` that opens the sign-in dialog, built in N) and "Request a quote" (link). Hidden labels where space is short.
- **Nav** (white, 72 px, sticky): logo (CSS glyph + "Malva", subline "Plumbing & Waste" hidden < 1180 px), links Plumbing · Waste management · About (`aria-current="page"` for the current section, 2 px navy underline), outline **Client portal** button, primary **Request a quote**, and a **Quote list (n)** link that appears only when n > 0 (client-resolved from `useQuoteList`, space reserved; hidden by default so layout does not shift). **Mobile (< 900 px): a menu button** (design gap, SO-01) opens a full-width panel with every link, the portal button and Request a quote; focus trapped, Escape closes, focus returns to the button.
- **Footer** (dark): 4 columns as the prototype; links to the 4 plumbing and 4 waste summaries go to the listings; Company: About, Request a quote, Client portal (button), Privacy notice (added by M).
- **Skip link** "Skip to content" first in the DOM.
- Shared components in `components/ui/`: `Button`/`LinkButton`, `ServiceCard`, `AudienceCard`, `Stat`, `CertChip`, `Testimonial`, `CheckList`, `CtaBand`, `PageHeader` (breadcrumb + h1 + lead), `Stepper`, `OptionCard`, `Field` (label, hint, error with `aria-describedby`/`aria-invalid`), `Dialog` (role `dialog`, labelled, focus trap, Escape, backdrop click, focus return), `Tag`, `SampleMarker` ("Sample content", used by I/J/M), `LiveRegion`.
- **Error pages:** `app/[locale]/error.tsx`, `global-error.tsx`, `not-found.tsx` with a link to both listings and Request a quote; `unauthorized.tsx`/`forbidden.tsx` shells for the portal.
- `app/[locale]/layout.tsx` composes top bar, nav, `<main id="content">`, footer; **no session read** (D20).
