## Design
As `bootstrap-malva-storefront/specs/malva-data-loading` and design decisions 9, 13.
- **Layouts never read the session** (D20): `app/layout.tsx` and `app/[locale]/layout.tsx` call no `cookies()`, `headers()`, `getSession()`. Per-visitor UI (nav quote-list count, sign-in state) is SWR after hydration in reserved space.
- `lib/ct/services.ts` (server-only): `getServiceBySlug(slug, locale)`, `getServicesByCategory(categoryKey, locale, { sector })`, `getCategoryTree(locale)`, `getRelatedServices(product)`. Listings use **`apiRoot.products().search()`** scoped to the default store (`storeProjection`/selection) — never `productProjections().search()`. Fetches wrapped with React `cache()` so `generateMetadata` and the page share one call; `unstable_cache` only for the category tree (60 s) and project config (300 s).
- `lib/mappers/service.ts` → app type `Service` (`slug, name, summary, description, category, sectors, frequencies, included, steps, records, faq, related, needsWasteDetails, images`) — **no price field** (D21).
- `lib/cache-keys.ts` (`KEY_CART`, `KEY_ACCOUNT`, `KEY_BUSINESS_UNITS`, helper `buKey(KEY, businessUnitKey)` → `[KEY, businessUnitKey]`), `hooks/useAccount.ts`, `hooks/useQuoteList.ts`, `hooks/useBusinessUnits.ts` — **placeholders** that return safe defaults (`null` / `[]`) until N/P; mutations throw; `mutate(KEY, data, { revalidate: false })` pattern; sign-out clears the three keys (`clearClientState(mutate)`).
- Headers: `next.config.ts` `headers()` sets `Cache-Control: no-store` for `/api/:path*` and `/:locale/account/:path*`.
- `scripts/check-routes.mjs`: parses `next build` output and fails if a route in the **public list** (`/[locale]`, `/[locale]/plumbing`, `/[locale]/waste-management`, `/[locale]/about`, services detail) is dynamic (λ/ƒ) instead of static/ISR (○/●).
- Smoke page `/[locale]` placeholder: token-styled heading, a message from `messages/en-US.json`, a server-rendered count of services from search; health report says if search indexing is missing (`GET /api/health` extension).
