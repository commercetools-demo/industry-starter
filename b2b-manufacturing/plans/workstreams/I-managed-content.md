## Design
Proof content (stats, accreditations, testimonials, audience cards, phone numbers, emails, hours) lives in JSON files in the repo (Q-010), each item carrying `sample: true|false`.
- `content/stats.json` (4 items: 4 h / 98.6% / 82% / 350+ with captions), `content/accreditations.json` (ISO 9001, ISO 14001, Licensed waste carrier + reg. no. `CBDU000000`, Gas Safe & WRAS approved), `content/testimonials.json` (3), `content/audiences.json` (4, in the stated order, each with `sector` key for the quote-form link), `content/contact.json` (emergency 0800 555 0142, commercial 0800 555 0100, email, hours Mon–Fri 7:30–18:00). Copy verbatim from `design/malva/source/Malva.html`. All start `sample: true` except `audiences` and the contact block, which are `sample: true` as well until SO-04.
- `content/schema.ts` (zod) validates every file; `lib/content.ts` (server-only) loads and returns arrays; **an empty array means the section is omitted**, never rendered empty.
- `<SampleMarker/>` (from H) renders on sample items, visible text "Sample content".
- Launch check `scripts/check-sample-content.mjs`: lists every `sample: true` item; with `--strict` (used by Z and by the release build) it fails when any remains.
