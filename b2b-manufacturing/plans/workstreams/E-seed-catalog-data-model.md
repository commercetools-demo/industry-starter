## Design
Everything in `plans/SEED-PLAN.md`, in the standalone package `seed/` (D14). Safety rules there are mandatory: prefix `mpw-`, project-key guard (refuse `*healthcare*`), reviewed manifest instead of wildcard deletion, idempotent, `--dry-run`.
- Package: `seed/package.json` (`tsx`, `vitest`, `typescript`, `@commercetools/platform-sdk@^8`, `@commercetools/ts-client@^4`, `dotenv`), scripts `check` (`tsc --noEmit && vitest run`), `seed`, `images`, `verify`, `reset`.
- Order of `seed.ts`: tax category → zone → shipping method → product types (`mpw-faq-item` first, then `mpw-service`) → categories → custom types → associate roles → products (create, set images from `data/product-images.json` when present, publish) → store → product selection (add all, assign to store) → demo companies and customers → portal custom objects.
- `verify.ts` implements the SEED-PLAN "Verification" list as assertions (counts, keys, USD 0 price, no `?` in image URLs, published, store+selection, roles, settings, search finds a service).
- Images: clean URLs in `src/data/*-images.json`, applied by `seed.ts`.
