## Design
`design/malva/specs/cart.md` (proposed, SO-02). The list **is a cart** in store `mpw-web`, currency per locale (USD or EUR), single shipping mode; lines are zero-priced and never displayed or totalled (D12, D21).
- `lib/ct/quote-list.ts`: anonymous visitors → `apiRoot.carts()` with `anonymousId` from the session, `store` `mpw-web`, `currency USD`, `country` and `currency` from the active locale (US/USD or DE/EUR), `shippingMode Single`; signed-in with a BU → `asAssociate(session).carts()` (F) with the same fields. Functions: `getQuoteList(session)`, `addService(session, sku, { frequency?, note? })`, `updateLine(session, lineItemId, patch)`, `removeLine(session, lineItemId)`. Line custom type `mpw-line-service` (`frequency`, `note`). Add by **sku**; duplicate add returns the existing line with `alreadyInList: true`. A service variant without a USD price makes the add fail with a generic message and an error log carrying the sku (test with a mocked `MissingPriceForProduct`-style error).
- Merge at sign-in is done by N's login (anonymous cart merge); P tests the end state through a fake: guest list of 2 + account list of 1 = 3 distinct lines.
- Routes: `GET/POST /api/quote-list`, `PATCH/DELETE /api/quote-list/lines/[id]` (anonymous allowed; mutations return the full list so the hook updates the cache from the response). `useQuoteList` real implementation (key `KEY_CART`), count exposed to the nav slot.
- Page `/[locale]/quote-list` (dynamic island on a static shell: the page shell is static; the table is client-rendered): table rows name (link), category tag, frequency `<select>` (only options valid for the service + One-off), notes field, Remove; right card "Services: n", **Continue to request**, **Add another service**, sentence "No payment is taken. We reply within one working day with a priced quote." Empty state "Your quote list is empty. Choose the services you want quoted." + links to both listings. Unavailable lines flagged "No longer available" and excluded from submission.
- PDP island: replaces L-06's placeholder: **Add to quote list** → added state with "View quote list"; nav count +1; already in list → added state, no duplicate.
- No discount-code, delivery or payment controls anywhere (spec).
