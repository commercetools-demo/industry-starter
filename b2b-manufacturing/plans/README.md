# plans/

Implementation plan for the Malva plumbing and waste-management website, written for junior developers to follow task by task.

| File | Purpose |
| --- | --- |
| `JUNIOR-GUIDE.md` | **Start here.** Rules, the task loop, tests, how to report manual testing, when to stop and ask |
| `DEPENDENCY-PLAN.md` | Workstreams A → Z, who depends on whom, parallel lanes, gates |
| `workstreams/<LETTER>-*.md` | One file per workstream: design, tasks, scenario checklist, browser recipe, definition of done |
| `STATUS.md` | Progress (counts generated by `verify-plan.mjs --sync`) and environment status |
| `DECISIONS.md` | Decisions already made (owner and verified platform facts) |
| `QUESTIONS.md` | Questions to the owner: answered, defaults, and the ones juniors add |
| `TODO-MANUAL-TESTING.md` | **Everything only the owner can do**: actions (OA), sign-offs (SO), manual tests (M) |
| `SEED-PLAN.md` | Seed data model and scripts (`../seed/`) |
| `SPEC-COVERAGE.md` | Which workstream implements which requirement |
| `PROJECT-FINDINGS.md` | Verified platform facts and environment findings |
| `IDEAS.md` | Parked ideas |
| `verify-plan.mjs` | `node plans/verify-plan.mjs [--sync]` — checks the plan is consistent with the specs |

Specs: `../openspec/changes/bootstrap-malva-storefront` and `../openspec/changes/malva-website`. Design: `../design/malva`.
