# Workstream K — Doctor list and search

**Depends on:** F, G, H
**Implements:** design-plp[Doctor list by consultation mode; Doctor card content; Doctor list pagination], product-listing-page, search-results-page, discovery-and-browse
**Skills:** commercetools-storefront, commercetools-platform

## Design
Routes `/[locale]/doctors/remote` and `/[locale]/doctors/office` (server-rendered), page head H1 "Remote sessions"/"Office visits", segmented control (route change, keeps filters), count line "N doctor(s)", filter bar (search by name/specialty, specialty select, city select **office only**, "Available today" checkbox). Filter/page state lives in the URL (`?q=&specialty=&city=&today=1&page=`); same URL = same listing; page past the last result → redirect/clamp to the last page. Results from the Product Search API (`lib/ct/search.ts`, G-04): filter `modes` contains the mode, facets `specialty`, `city`; the fee shown is the price on the channel of the current mode. **"Available today" is not a catalog facet** (design-plp): computed from `listFreeSlots` (F-02) for the doctors on the current page candidates — implement as: search narrows by the other filters, then availability is evaluated per candidate (≤ 50) in parallel and filtered/sorted. Default sort (Q-030): soonest availability, then rating; page size 9 (Q-031); "near you" = city filter only (Q-032). Availability badge: success "Available today", info "Next: Tue 14", none if no slot in 7 days. Doctor card = real link `/doctor/:key?m=<mode>` (whole card focusable/clickable via stretched link), 56 px peach avatar or portrait.
Search (D-017/Q-033): header and home search submit to `/search?q=`; results page groups **Doctors** and **Medicines**; full-text over doctor name/specialty/clinic and medication name; exact medication SKU/part number resolves to that product first (search-results-page); a query that matches nothing shows suggestions (specialty chips) — a real "did you mean" correction is not provided (the spec's "Misspelt query" scenario is satisfied by commercetools fuzzy matching, documented); unsupported-language query message. Discovery: specialty browse chips and `/doctors/remote?specialty=dermatology`. Doctors have no price filter; medicines appear in search only (browse lives under Prescriptions).
