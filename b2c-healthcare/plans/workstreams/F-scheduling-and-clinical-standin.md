## Design
Server modules and seed data for everything that is **not** catalog data. All are Custom Objects (Q-001, Q-004) unless noted, behind interfaces so a real scheduler/EHR can replace them. **Demo stand-in**: the README of `lib/clinical/` says so in its first line; data is synthetic.
- Containers: `malva-schedule` (key = doctor product key; value `{ timezone, weekly: { mon: ['09:00',…], … }, slotMinutes: 30 }`), `malva-slot-claim` (key `<doctorKey>|<mode>|<ISO start UTC>`; created with `version: 0` so a second create fails with 409 → "slot taken"), `malva-booking` (key = reference `BK-<base32>`; value: `doctorKey, mode, startsAt, patientRef|guest{name,email,phone}, reason, createdAt, status, expiresAt?`), `malva-rx` (key `RX-48213`; value: `patientRef, prescriber, issuedAt, refillsLeft, lines[{lineRef, sku, name, sig, qty}]`), `malva-lab` (key id; `patientRef, name, collectedAt, status, orderedByDoctorKey, laboratory, note, results[{name, value, unit, low, high}]`), `malva-credential` (key = patientRef + class; `class, issuer, validFrom, validTo, status`), `malva-counter` (order numbers, key `order`), `malva-ratelimit` (key per customer).
- Free slots = pattern ∩ next 7 days in the **doctor's time zone** − claimed slots − slots < 2 h from now (Q-003). "Today" = today in the clinic zone. Remote slots are returned with the zone name for display.
- `patientRef` is an opaque per-project id (`pt_<random>`) stored on the Customer custom type `mlv-patient`; RX/labs link to it, never to name/email.
- Reviews: commercetools **Review** objects (`rating`, text, `custom.verifiedPatient`), 3–6 per doctor, so rating statistics roll up on the product.
- Demo patients (password from `SEED_PATIENT_PASSWORD`, email verified): **Sam Rivera** (both prescriptions `RX-48213` — 0 refills left, the "cannot dispense" case — and `RX-77102` 3 refills; five labs; one past booking; funding scheme "Demo Health Plan"; credential for one controlled class), **Alex Chen** (empty account), **Jordan Lee** (one RX valid + one expired RX). Labs, prescriptions and reviews copy the prototype fixtures (`app-core.jsx`).
