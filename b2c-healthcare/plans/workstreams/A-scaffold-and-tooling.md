## Design
Create `b2c-healthcare/site/` exactly as `openspec/changes/bootstrap-storefront/design.md` (decisions 1–4, 11, target layout). Nothing but the scaffold, gate, lint rules and test helpers: no pages beyond the Next default placeholder (the smoke page is H-10). Versions: `next@^16`, `next-intl@^4`, React 19, TypeScript strict, Tailwind v4 through `@tailwindcss/postcss` with **no** `tailwind.config.*`, `swr`, `jose`, `@commercetools/platform-sdk@^8`, `@commercetools/ts-client@^4`. Test stack: Vitest + Testing Library + jsdom. Lint: ESLint flat config (import restrictions) plus oxlint with the design rules (rules arrive in B). `create-next-app` must run with `--tailwind=false` (passing `--tailwind` installs v3).
`npm run check` = `tsc --noEmit` → lint → `node scripts/check-versions.mjs` → `node scripts/check-token-parity.mjs` (stub that exits 0 until B) → `vitest run`. `npm run build` fails on type errors.
