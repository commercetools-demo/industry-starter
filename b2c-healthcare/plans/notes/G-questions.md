# Workstream G: questions and the defaults chosen

| # | Question | Default chosen |
| --- | --- | --- |
| 1 | `withCartRetry(fn)`: how does the helper "refetch"? | `fn` is a closure that reads the current cart (id, version) itself and applies the update; on 409 it is called once more. The helper stays free of cart types. Documented in the file and README. |
| 2 | Root layout cannot write cookies, but the spec says a stale `cartId` is cleared. | `getActiveCartSafe` calls `clearCart()` in a try/catch; in a Server Component render the clear is skipped (read-only cookies), the page renders with `KEY_CART: null`, and the cart endpoint (Route Handler, workstream H) clears it for real. Task called it a stub returning null; it is a real read (summary: id, version, itemCount, currencyCode). |
| 3 | `lib/session.ts` threw at import without `SESSION_SECRET`, so any route or layout importing it broke `next build` with an empty env (A-question 5). | Secret is resolved lazily on first use (`secret()`); still a hard failure at first read/write, no fallback key. Small edit to D's file. |
| 4 | `setLocale` signature. | `setLocale({ locale })` only; country and currency derive from `COUNTRY_CONFIG` (`withRegion` in `session-core.ts`). Partial inputs are not representable. `cartId` is cleared when the stored currency differs (also when no currency was stored yet). The route validates against `getValidCountryConfig()` and rejects: no locale, unsupported/excluded locale, country or currency contradicting the table. D's `withLocale` is kept. |
| 5 | After sign-out `mutate(key, undefined)` would let SWR fall back to the layout fallback (old cart reappears until a full reload). | `clearPatientState` writes `null` (tested against a fallback). |
| 6 | Region test for "language enabled in project". | A region counts as enabled when the project lists its country, its currency, and either the locale tag (`en-US`) or the base language (`en`). |
| 7 | Product Search facet/attribute names and field types. | Taken from SEED-PLAN (`specialty`, `city`, `modes` as enum; `rxOnly` boolean) with `fieldType: 'enum'`/`'boolean'`. Not verified against the live index; adjust after E runs. Price sort uses `variants.prices.centAmount` mode min/max filtered to the currency. |
| 8 | Price channel selection for doctor fees. | Mapper reads all prices of the master variant and picks the one in the visitor's currency on channel key `mlv-remote`/`mlv-office` (expanded via `masterVariant.prices[*].channel`, or an id-to-key map). Search requests add that expand. The `priceChannel` projection parameter needs a channel id and is only sent when `priceChannelId` is given. |
| 9 | Where does the shipping-method list get rates for a cart? | `getShippingMethods` is the informational public read (all active methods, zone rates). Cart-matching rates are a separate uncached call for the cart/checkout workstreams. |
| 10 | `Category`, `ProductBasics`, `CartSummary`, `AccountUser`, `ShippingMethodInfo` types. | Added to `lib/types.ts` (additive) because G-03/05/06 need them before G-09; later workstreams extend. |
| 11 | `React.cache()` only memoizes inside a Server Components request, so a unit test cannot prove de-duplication. | Tests mock `react`'s `cache` with a memoizer and assert the export is `cache(fn)` and that two calls hit the client once. The real behaviour needs the browser check in G-todos. |
