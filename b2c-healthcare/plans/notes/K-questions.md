# Workstream K: questions and the defaults chosen

| # | Question | Default chosen |
| --- | --- | --- |
| 1 | Fixture switch for browser checks without credentials. | `MALVA_FIXTURES=1` (dev only; `lib/ct/fixtures.ts` returns nothing when `NODE_ENV=production`, and the dynamic import is dead-code-eliminated so the seed data is not in production bundles). The doctor list and `/search` then read `scripts/seed/data` (doctors, schedules via `candidateSlots`, reviews, medications). `next dev` still needs the CTP_* env names (dummy values work: nothing is called). |
| 2 | G's enum field paths were wrong for Product Search. Docs: enum attributes are searched on `variants.attributes.<name>.key`, a set of enum uses `fieldType: set_enum`. | Fixed in `lib/ct/search-query.ts` (filters and the distinct facets) and G's test updated. Still unverified against the live index (K-todos). |
| 3 | Doctor search "by name, specialty or clinic" but `clinicName` is not a searchable attribute in the seed product type. | Text matches name (full text OR fuzzy) and specialty (typed text matched against the specialty labels, then an exact `specialty.key` filter). Clinic is not searched; making `clinicName` searchable is a seed-type change (workstream E). |
| 4 | Default order needs availability, which is not a facet. | Search returns up to 50 candidates (name order); availability is read per candidate in parallel (`listFreeSlots`, 7 days), then sorted soonest, rating, name, filtered for "Available today", paged in memory. A doctor whose schedule cannot be read shows no badge (not an error). The total counts doctors after the today filter. |
| 5 | "Today" definition. | The slot's clinic-local date equals today's date in the clinic time zone (so 21:30 New York is "today" although it is tomorrow in UTC). |
| 6 | Cached facets (K-04). | Filter options come from static lists (`lib/specialties.ts`, kept in sync with the seed enums by a test), so no search or cache call is needed; facet counts are returned by `searchDoctors` but not shown. No `unstable_cache` added (the data cannot go stale). |
| 7 | Page past the last result. | The page redirects (locale-aware `redirect`) to the last page that has results; `searchDoctors` itself also clamps. |
| 8 | Page size. | `doctorPageSize()` = 9, overridden by env `DOCTOR_PAGE_SIZE` (1-50). |
| 9 | Search page: medicines have no product page yet. | Medicine hits are cards without a link, plus a "Find your prescription" link to `/prescriptions`. Doctor hits reuse `DoctorCard` (no availability badge, mode = first offered mode). |
| 10 | Exact part number. | A query with no spaces that contains a digit or dash is also looked up with `exact variants.sku` (case-insensitive) restricted to medicines; a hit is shown first with "Matched part number X". Doctor SKUs (`DOC-...`) are not resolved (Q-033). Run as a separate parallel call, not one compound query, to know which hit was the exact one. |
| 11 | Misspelt query. | `fuzzy` (level 2, the API lowers it by term length) OR-ed with the full-text name match, as documented; no correction is claimed. |
| 12 | Unsupported language guard. | A query whose letters are all outside the storefront language's script (Latin for `en`) gets the "language not supported" state without searching. Mixed queries are searched. |
| 13 | Header and home search entry. | `components/search/SearchForm.tsx` (a no-JS GET form to `/<locale>/search?q=`) is ready; the header (workstream H) has no search control and was not edited. See K-missed. |
| 14 | Shared files touched. | `messages/en-US.json` (+`doctors`, `search`), `lib/types.ts` (+`DoctorAvailability`, `DoctorListItem`), `lib/ct/search-query.ts` (+`extraQuery`, `buildNameMatch`, key paths). `lib/nav.ts`, `package.json` untouched. |
| 15 | Filter text input. | Applied after a 350 ms pause or Enter via `router.replace`; page resets to 1 on every filter change. The city value stays in the URL when switching to remote (ignored there, kept when switching back). |
