| # | Question | Default chosen |

| 1 | **Licence of the committed photos.** The public Pexels search endpoint used by the grocery script (`/api/v3/getty-media/photos`, response `type: "ad_medium"`) answers with iStock (Getty) partner thumbnails hosted on `media.istockphoto.com`, not with photos under the Pexels licence. D-040 says "all images come from Pexels (royalty-free)". All 62 committed URLs (56 product photos and 6 banner slots) are iStock hosted. | Followed the instruction (public endpoint, clean URLs, 200 verified, no credit shown) and added the host to the CSP `img-src` (`netlify.toml`) and `next.config.ts`. Added an official-API path: with `PEXELS_API_KEY` in the shell `update-images.ts` calls `api.pexels.com/v1/search` (every photo then really is Pexels-licensed; `npm run seed:images:json` rewrites the JSON, then commit). **Owner: if iStock thumbnails are not acceptable, create a free Pexels API key and run it once.** No key exists in this environment. |
| 2 | Searchability is called "irreversible per type", but the API has `changeIsSearchable`. | The seed sends `changeIsSearchable` (and `addAttributeDefinition`, `addPlainEnumValue`, `changeLabel`) for an existing product type, so a project seeded before AC is repaired by `npm run seed`. What commercetools really forbids (attribute type change, `isRequired` change, tightening a constraint, removing an attribute) stops the run with the reset to run. `SEARCHED_ATTRIBUTES` in `data/types.ts` carries the loud warning; `seed:verify` checks it; a unit test fails when code searches an attribute that is not searchable. |

| 4 | RecurringOrder DELETE accepts `dataErasure` (OpenAPI), but `scripts/privacy/erase-patient.ts` only cancels them ("no DELETE exists", X note). | The full reset deletes them with `dataErasure=true` before the customer erasure. `erase-patient.ts` was NOT changed (workstream X's file); see AC-missed. |
| 5 | Which customers does `--include-customers` erase? | Every customer whose email is on `example.com` (the seed's patients and test sign-ups), the same allow-list as `synthetic.ts`; plus example.com guest carts and orders. Never another email. |
