# Support

This repository is **commercetools-labs** reference code. It is freely available under the [MIT License](LICENSE), provided **AS IS and UNSUPPORTED**.

- There is no SLA, no support channel and no commitment to fix bugs, answer questions or keep the code compatible with future commercetools releases.
- It is not part of the commercetools product and is not covered by any commercetools support agreement.
- Issues and pull requests may go unanswered. You are welcome to fork the code and adapt it.
- Read and test the code before you rely on any of it in production. Each project's "before production" notes in its `plan/` or `plans/` folder list what is stubbed.

For commercetools product support, use the [official support channels](https://docs.commercetools.com/), not this repository.
