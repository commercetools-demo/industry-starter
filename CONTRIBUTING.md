# Contributing

This is commercetools-labs reference code: freely available, AS IS and **UNSUPPORTED** (see [SUPPORT.md](SUPPORT.md)). Contributions are welcome but not guaranteed a response or a merge.

- Each project is self-contained (own dependencies, lockfile, plan and specs). Work inside one project directory and follow its `site/README.md`.
- Run the project's quality gate (`npm run check` in its app directory, where defined) before opening a pull request.
- Keep changes small and focused, and do not commit secrets, `.env` files or customer data.
- Every source file carries the SPDX header (`SPDX-License-Identifier: MIT`). New files need it too.
- By contributing you agree your work is licensed under the [MIT License](LICENSE).
